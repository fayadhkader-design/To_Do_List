# Carolina Daybook

A responsive UNC–Chapel Hill-inspired to-do list with an integrated monthly calendar.

## Run locally

Install a current Node.js release, then run:

```bash
pnpm install
pnpm dev
```

Open the local URL printed in the terminal.

## Production build

```bash
pnpm build
```

The compiled site is written to `dist/`. Tasks are saved in the browser's local storage.
